# 🗞️ iPortfolio Drafts & Instant Publishing Desk

Welcome to your automated content publisher!

## How to add content easily:

### Option 1: Drop a file in this `content/drafts/` folder
1. Create a `.md` file in this folder (or duplicate `sample-project.md` or `sample-essay.md`).
2. Add title, summary, type (`project` | `essay` | `book`), and paragraphs.
3. Run in your terminal:
   ```bash
   npm run publish
   ```
4. Done! Your portfolio is updated immediately!

### Option 2: Use the Web Pressroom Desk (`/admin`)
Visit `http://localhost:3000/admin` on your browser to use the interactive visual publisher form!
